## 🧠 Wissens-Briefing

Der Gauß-Algorithmus nutzt drei erlaubte Operationen, die die Lösung nicht ändern:

1. Gleichungen (Zeilen) vertauschen.
2. Eine Zeile mit einer Zahl ( $\\neq 0$) malnehmen.
3. Eine Zeile zu einer anderen addieren (oder ein Vielfaches davon).

**Ziel:** Wir wollen links unten Nullen haben.

$\\begin{pmatrix} \* & \* & \* \\\\ 0 & \* & \* \\\\ 0 & 0 & \* \\end{pmatrix}$

Dann steht in der letzten Zeile: $0x + 0y + 3z = 6 \\Rightarrow z=2$ . Das ist leicht lösbar!

## ⚠️ Typische Fallstricke

- **Rechenfehler:** Ein Vorzeichenfehler in Schritt 1 ruiniert das ganze Ergebnis.
- **Gleichung vs. Matrix:** Manche vergessen, die Operation auch auf den Ergebnisvektor $\\vec{b}$ (die rechte Seite) anzuwenden!
- **Verlust:** Niemals eine Zeile einfach löschen oder mit 0 multiplizieren. Informationen gehen verloren.

### P1: Operation (Analog): Gegeben Zeile I: $(2, 4 | 8)$ und Zeile II: $(1, 5 | 7)$. Ziel: Erzeuge eine 0 an der ersten Stelle von Zeile II. Welche Operation führst du durch? Berechne die neue Zeile II. (K3)

**Operation:** Damit die besagte Stelle ($1$) zur Null wird führen wir überall die passende Operation aus → $II_{neu} = II - \\frac{1}{2} \\cdot I$

**Berechnung:**

- Stelle 1: $1 - \\frac{1}{2} \\cdot 2 = 1 - 1 = 0$ ✅
- Stelle 2: $5 - \\frac{1}{2} \\cdot 4 = 5 - 2 = 3$
- Rechte Seite: $7 - \\frac{1}{2} \\cdot 8 = 7 - 4 = 3$

**Neue Zeile II:** $(0,3|3)$

$I:$ $2x_1 + 3x_2 = 8$

$II_{neu} = II - \\frac{1}{2} \\cdot I$

$II_{neu}​:1−0,5⋅2=0,\\quad4−0,5​⋅3=2,5​,\\quad7−0,5⋅8=3$

Wir erhalten also dasselbe Ergebnis, wie in der vorangegangenen, bereits überprüften Aufgabe.

### Z1: Implementiere die Funktion eliminate(matrix), die eine Matrix in Stufenform bringt (Python). (K5)

```python
# ---
# m532_Z1:
def eliminate(A, b):
    rows = len(A)  # cols count
    cols = len(A[0])
    A = [row[:] for row in A]
    b = b[:]

    for pivot in range(cols):
        if A[pivot][pivot] == 0:  # check for 0
            for k in range(pivot + 1, rows):  # rows below
                if (
                    A[k][pivot] != 0
                ):  # another indirect 0 check, swaps if below is not 0
                    A[pivot], A[k] = A[k], A[pivot]
                    b[pivot], b[k] = b[k], b[pivot]
                    break
                else:
                    continue
        for i in range(pivot + 1, rows):
            factor = A[i][pivot] / A[pivot][pivot]
            for j in range(cols):
                A[i][j] = round(A[i][j] - (factor * A[pivot][j]), 5)
            b[i] = round(b[i] - (factor * b[pivot]), 5)
    return A, b
```

### Z3: Recherchiere den Unterschied zwischen "Gauß" und "Gauß-Jordan" Algorithmus. (K2)

Beide Verfahren starten gleich - Vorwärtselimination bis zur Stufenform. Der Unterschied liegt im zweiten Schritt:

|     | Gauß | Gauß-Jordan |
| --- | --- | --- |
| **Ziel** | Obere Dreiecksmatrix | Einheitsmatrix (Diagonale = 1, alles andere = 0) |
| **Auflösung** | Rückwärtseinsetzen nötig | Lösung direkt ablesbar |
| **Aufwand** | Weniger Operationen | Mehr Operationen |

Gauß-Jordan eliminiert nicht nur nach unten, sondern danach auch nach oben (und normiert die Diagonale auf 1). Das Ergebnis ist die **reduzierte Zeilenstufenform (RREF)**, aus der man $\\vec{x}$ direkt ablesen kann - kein Rückwärtseinsetzen nötig.
