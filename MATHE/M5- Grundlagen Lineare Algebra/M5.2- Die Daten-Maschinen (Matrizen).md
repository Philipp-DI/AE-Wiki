### Aufgabenstellung

Euer Team entwickelt einen universellen "Matrix-Rechner" (`ChainReactor`), der mehrstufige Prozesse berechnet. **Wählt euer Szenario:**

- _A (NeuroVision):_ Bild-Filter. Input: Pixel-Vektor. Prozess 1: Unschärfe-Matrix. Prozess 2: Kontrast-Matrix.
- _B (PolyRender):_ 3D-Engine. Input: Objekt-Koordinaten. Prozess 1: Rotation um X-Achse. Prozess 2: Skalierung (Größenänderung).

**Die 5 Rollen (Puzzle-Prinzip):**

1. **Der Matrix Architect:** Du modellierst die Realität. Erstelle für das gewählte Szenario zwei sinnvolle Matrizen $M_1$ und $M_2$ (z.B. zwei Produktionsstufen oder zwei Transformationen) sowie einen Input-Vektor $\\vec{v}$ (K5).
2. **Der Arithmetic Core Dev:** Du baust den Motor. Implementiere die Funktion `matrix_vector_mult(Matrix, Vector)`. Sie berechnet den ersten Schritt: $\\vec{z} = M_1 \\cdot \\vec{v}$ (K3).
3. **Der Chaining Engineer:** Du verkettest die Prozesse. Implementiere `matrix_matrix_mult(MatrixA, MatrixB)`. Berechne die "Gesamt-Matrix" $M_{ges} = M_2 \\cdot M_1$ (Achtung: Reihenfolge beachten!) (K4).
4. **Der Dimension Guard:** Du sicherst die Stabilität. Implementiere eine Prüfung (`check_dimensions`), die sicherstellt, dass Spalten von A gleich Zeilen von B sind, bevor gerechnet wird. Verhindere Programmabstürze (K4).
5. **Der Product Owner:** Du validierst das Ergebnis. Berechne einmal den Weg über den Zwischenschritt ( $\\vec{z}$ berechnen, dann $M_2 \\cdot \\vec{z}$ ) und einmal über die Gesamtmatrix ( $M_{ges} \\cdot \\vec{v}$). Zeige im Review, dass das gleiche Ergebnis herauskommt (Assoziativität) (K6).

### Ergebnis-Artefakt

Ein Python-Skript (`chain_reactor.py`) mit eigener Implementierung der Multiplikationen (kein Numpy für die Logik!) und einer Demo-Ausgabe des Szenarios.

### Gewähltes Szenario

_B (PolyRender):_ 3D-Engine. Input: Objekt-Koordinaten.

Prozess 1: Rotation um X-Achse.

Prozess 2: Skalierung (Größenänderung).

- $M_1$ = Rotationsmatrix
- $M_2$ = Skalierungsmatrix
- $\\vec{v}$ = Koordinaten als Vektor `[x, y, z]`

Kommentar zu meiner Frage aus dem Pre-Review

```python
import math as m
from functools import wraps

def check_dimensions(func):
    @wraps(func)
    def wrapper(a, b):
        cols_a = len(a[0])
        rows_b = len(b) if isinstance(b[0], list) else len(b)
        if cols_a != rows_b:
            raise ValueError(f"Dimensionsfehler: A hat {cols_a} Spalten, B hat {rows_b} Zeilen. Müssen identisch sein.")
        return func(a, b)
    return wrapper

@check_dimensions
def matrix_vector_mult(matrix, vector):
    return [sum(a * b for a, b in zip(row, vector)) for row in matrix]

@check_dimensions
def matrix_matrix_mult(matrix_a, matrix_b):
    transposed_b = list(zip(*matrix_b))
    result = [[round(sum(a*b for a,b in zip(row_a, col_b)), 10) for col_b in transposed_b] for row_a in matrix_a]
    return result

def build_rotation_x(angle_deg):
    a = m.radians(angle_deg)
    cos_a = round(m.cos(a), 10)
    sin_a = round(m.sin(a), 10)
    return [[1, 0, 0], [0, cos_a, -sin_a], [0, sin_a, cos_a]]

def build_scale(sx, sy, sz):
    return [[sx, 0, 0], [0, sy, 0], [0, 0, sz]]

def print_matrix(label, matrix):
    print(f"\n{label}:")
    for row in matrix:
        print("  ", [round(x, 4) for x in row])

def print_vector(label, vector):
    print(f"\n{label}:")
    print("  ", [round(x, 4) for x in vector])

if __name__ == "__main__":
    print("ChainReactor -- Szenario B: PolyRender")

    # Input-Vektor: 3D-Koordinaten [x,y,z]
    v = [4, -2, 3]

    # M1: Rotationsmatrix (x-Achse)
    angle_deg = 90
    MATRIX_1 = build_rotation_x(angle_deg)

    # M2: Skalierungsmatrix
    scale = 2 # Uniforme Skalierung
    MATRIX_2 = build_scale(scale, scale, scale)

    print_vector("Input-Vektor v (Koordinaten)", v)
    print_matrix(f"M1 -- Rotation x-Achse ({angle_deg}°)", MATRIX_1)
    print_matrix(f"M2 -- Skalierung ({scale}x)", MATRIX_2)

    # Weg 1: Zwischenschritt
    print("\nWeg 1 -- per Zwischenschritt:")

    z = matrix_vector_mult(MATRIX_1, v)
    print_vector("z = M1 * v", z)

    result_1 = matrix_vector_mult(MATRIX_2, z)
    print_vector("Ergebnis = M2 * z", result_1)

    # Weg 2: Gesamtmatrix
    print("\nWeg 2 -- per Gesamtmatrix:")

    M_ges = matrix_matrix_mult(MATRIX_2, MATRIX_1)
    print_matrix("M_ges = M2 * M1", M_ges)

    result_2 = matrix_vector_mult(M_ges, v)
    print_vector("Ergebnis = M_ges * v", result_2)

    # Vergleich (Assoziativität)
    tolerance = 1e-9 # Um pythonische Rundungsfehler zu vermeiden/umgehen
    match = all(abs(a - b) < tolerance for a, b in zip(result_1, result_2)) # Wird zu true, wenn all() leer is.
    print(f"\nAssoziativität wenn: Weg 1 {result_1} == Weg 2 {result_2} \n=> {'Identisch!' if match else 'Abweichung!'}")
```
