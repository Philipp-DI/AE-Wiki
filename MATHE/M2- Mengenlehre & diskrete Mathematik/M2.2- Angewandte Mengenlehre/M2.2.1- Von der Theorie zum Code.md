# M2.2.1- Von der Theorie zum Code - Mengenoperationen in SQL

Als **angehender Datenbankentwickler**  
möchte ich **Mengenoperationen direkt in SQL-Abfragen übersetzen**,  
damit ich **Daten aus einer relationalen Datenbank präzise und performant selektieren kann.**

# Celebration Criteria (Lernziele)

- Wir können die Vereinigungsmenge mit `UNION` in SQL abbilden.
- Wir können die Schnittmenge mit `INTERSECT` in SQL abbilden.
- Wir können die Differenzmenge mit `EXCEPT` in SQL abbilden.

# Wissens-Briefing

- **SQL-Mengenoperatoren:** Direkte Übersetzung der Konzepte in `UNION`, `INTERSECT`, `EXCEPT`.

# Aufgaben

1.  **Vereinigung:** Erstellt eine einzige Liste mit den Nachnamen aller Autoren und aller Leser. Nutzt `UNION`, um Duplikate zu vermeiden.
2.  **Schnittmenge:** Findet die `buch_id`s aller Bücher, die sowohl dem Genre 'Belletristik' als auch dem Genre 'Kinderbuch' zugeordnet sind (falls es solche gibt). Nutzt `INTERSECT`.
3.  **Differenz:** Findet die `leser_id`s aller Leser, die im Januar 2024 ein Buch geliehen haben, aber NICHT im Februar 2024. Nutzt `EXCEPT`.
4.  **Kombination:** Findet alle Leser (`leser_id`), die entweder Bücher von 'George Orwell' ODER von 'J.K. Rowling' ausgeliehen haben, aber NICHT von beiden._Tipp:_ Dies erfordert eine Kombination von `UNION` und `EXCEPT`.
