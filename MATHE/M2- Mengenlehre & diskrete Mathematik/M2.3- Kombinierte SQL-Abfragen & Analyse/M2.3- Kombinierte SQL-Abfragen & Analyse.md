# Spezifikation

**Teilmenge (**`WHERE`**):** `SELECT ... WHERE bedingung` erzeugt eine gefilterte Teilmenge, bevor sie mit einem Set-Operator verglichen wird.

**Verknüpfung (**`JOIN`**):** `... JOIN ... ON ...` verbindet Tabellen, um zusammengehörige Daten für einen Mengenvergleich zu finden.
