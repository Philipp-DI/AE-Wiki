# Wissens-Briefing

- **Quadratische Gleichung:** Eine Gleichung, bei der die Variable (x) im Quadrat (x²) vorkommt.
- **Binomische Formeln:**
    1.  `(a + b)² = a² + 2ab + b²`
    2.  `(a - b)² = a² - 2ab + b²`
    3.  `(a + b)(a - b) = a² - b²`
- **Normalform:** `x² + px + q = 0` (für die p-q-Formel)
    - `x₁ + x₂ = -p`
    - `x₁ * x₂ = q`
- **Allgemeine Form:** `ax² + bx + c = 0` (für die a-b-c-Formel)
- **p-q-Formel:** `x₁,₂ = -p/2 ± √((p/2)² - q)`
- **a-b-c-Formel (Mitternachtsformel):** `x₁,₂ = (-b ± √(b² - 4ac)) / 2a`
- **Diskriminante (D):** Der Term unter der Wurzel (`b² - 4ac` oder `(p/2)² - q`).
    - D > 0: Zwei Lösungen
    - D = 0: Eine Lösung
    - D < 0: Keine reelle Lösung

    <br/>$x^2+2x×5 +25$\=$x^2+10x+25$  
    
2.  Faktorisiere mit der 3. binomischen Formel: `x² - 49`  
    <br/>$(x+7)×(x-7) = x^2-49$  
    
3.  Bringe die Gleichung `2x² + 8x - 10 = 0` in die Normalform.  
    <br/>$2x² + 8x - 10$ |÷2  
    $x² + 4x - 5 = 0$ → Satz von Vieta: x<sub>1</sub> + x<sub>2</sub> = -4 ; x<sub>1</sub> × x<sub>2</sub> = -5 **(Subscript in Math Inline, wie?)**  
    
4.  Löse die Gleichung `x² - 6x + 8 = 0` mit der p-q-Formel.  
    <br/>x<sub>1,2</sub> \= -(-6/2) ± √((-6/2)<sup>2</sup> - 8) = 3 ± √1 **(Subscript in “Code”, wie?) (Wurzelzeichen?)**  
    x<sub>1</sub> = 4  
    x<sub>2</sub> = 2  
    
5.  Löse die Gleichung `3x² - 9x - 12 = 0` mit der a-b-c-Formel. **(÷3 und Satz von Vieta = einfacher)**  
    <br/>​​`x₁,₂ = (9 ± √(9² - 4x3x-12)) / 2x3`  
    `x₁,₂ = (9 ± √(81 + 144)) / 6`  
    `x₁,₂ = (9 ± 15) / 6`  
    `x₁ = (9 + 15) / 6 = 24 / 6 = 4`  
    `x₂ = (9 - 15) / 6 = -6 / 6 = -1`
