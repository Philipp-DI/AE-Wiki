# Notizen - komb. Dreisatz

_“Ein Team von_ **_2 Systemintegratoren_** _benötigt_ **_6 Stunden_**_, um_ **_10 Server_** _mit einem Standard-Image zu betanken. Wie viele Stunden würde ein Team von_ **_3 Integratoren_** _benötigen, um_ **_25 Server_** _zu betanken?”_

x = neue Stundenanzahl  
Ausgang = 6 Std.

Alt / neu = Antiproportional = 2/3  
Neu / alt = Proportional = 25/10

x = 6 _(2/3)_ (2,5) = 10 || 3 Integratoren brauchen für 25 Server = 10 Std.

AP = alt / neu = 5/4  
P = neu / alt = 12000 / 10000

_“Eine Datenmigration von_ **_500 GB_** _dauert über eine_ **_1 Gbit/s_** _Leitung_ **_75 Minuten_**_. Wie lange würde eine Migration von_ **_1200 GB_** _über eine_ **_2,5 Gbit/s_** _Leitung dauern?”_

x = neue Zeit / Minuten  
Basis = 75 min.

Proportional = neu / alt = 1200 / 500  
AP = alt / neu = 1 / 2,5

x = 75 _(1200/500)_ (1/2,5) = 72 || Für 1200 GB brauchen wir bei einer Geschwindigket von 2,5 Gbit/s = 72 min.
