# Quiz- Funktionale vs. nicht-funktionale Anforderungen

📌 Quiz: Funktionale vs. nicht-funktionale Anforderungen  
<br/>Frage 1  
Welche der folgenden Anforderungen ist funktional?  
a) Das System muss eine Benutzerregistrierung ermöglichen.  
b) Das System muss innerhalb von 5 Sekunden starten.  
c) Die Software soll eine hohe Verfügbarkeit von 99,9 % gewährleisten.  
d) Der Computer darf nicht lauter als 30 dB im Betrieb sein.  
<br/>Frage 2  
Ein Kunde sagt: „Der PC soll Spiele in 4K-Auflösung flüssig darstellen können.“  
Handelt es sich um eine funktionale oder nicht-funktionale Anforderung?  
<br/>Frage 3  
Ordne zu:  
<br/>„Das System muss Rechnungen automatisch per E-Mail versenden.“  
<br/>„Das System darf nur 20 % CPU-Auslastung verbrauchen.“  
<br/>„Die Anwendung muss auf Windows, Linux und macOS lauffähig sein.“  
<br/>„Der Nutzer kann im Online-Shop Produkte in den Warenkorb legen.“  
<br/>Frage 4  
Richtig oder falsch?  
a) Funktionale Anforderungen beschreiben, was ein System leisten soll.  
b) Nicht-funktionale Anforderungen beschreiben, wie das System seine Leistung erbringt.  
c) „Hohe Benutzerfreundlichkeit“ ist ein funktionales Kriterium.  
d) „Das System darf nicht abstürzen“ ist nicht-funktional.  
<br/>Frage 5  
Ein Kunde sagt:  
<br/>„Der PC soll leise arbeiten.“  
<br/>„Der PC soll Office-Programme ausführen können.“  
Welches ist funktional, welches nicht-funktional?  
<br/>✅ Lösungen  
<br/>Frage 1: a = funktional, b/c/d = nicht-funktional  
Frage 2: nicht-funktional (Performance-Anforderung)  
Frage 3:  
1 = funktional,  
2 = nicht-funktional,  
3 = nicht-funktional,  
4 = funktional  
Frage 4:  
a = richtig,  
b = richtig,  
c = falsch,  
d = richtig  
Frage 5:  
„leise arbeiten“ = nicht-funktional,  
„Office-Programme ausführen können“ = funktional
